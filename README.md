# 仓库源码加密说明

## 背景

本仓库的 `.py` 与 `.php` 源文件在传输和静态存储阶段使用对称加密保护，
以降低明文源码在第三方工具、日志、镜像等场景下的暴露面。
加密后的文件保留原扩展名，内容为 base64 编码的密文，无法被解释器直接执行。

因此，刚克隆下来的仓库**不能直接阅读或运行**，需要先执行启动脚本解密。

## 如何解密：运行根目录的 start.sh

仓库根目录提供了统一入口脚本 `start.sh`。它负责环境检查、依赖安装，
并调用真正的加解密脚本完成解密。你不需要手动定位或直接调用那个脚本。

```bash
# 在仓库根目录执行
./start.sh

# 仅查看当前是加密还是明文状态，不做任何修改
./start.sh --check-only
